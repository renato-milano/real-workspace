# real-workspace

Workspace in realtà mista per Meta Quest 3: le finestre del Mac diventano pannelli nella stanza, e gli agenti
AI (Claude Code, Codex) si comandano a voce.

```
apps/bridge   Electron sul Mac: cattura finestre, WebRTC, signaling (porta 8443)
apps/xr       Client WebXR (Meta IWSDK) per il browser del Quest (porta 8081)
docs/         Stato del progetto e risultati degli spike
```

Stato attuale e comandi per avviare: [`docs/fase0-stato.md`](docs/fase0-stato.md).
